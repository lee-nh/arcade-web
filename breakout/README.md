# 🧱 브레이크아웃: 클래식 벽돌깨기 (Breakout Classic)

정통 오락실 아케이드 감성을 현대적으로 재해석한 **HTML5 Canvas 기반 고전 벽돌깨기 게임**입니다.
별도의 설치나 프레임워크 없이 웹 브라우저에서 즉시 실행됩니다.

---

## 🎮 게임 특징

1. **5가지 다채로운 스테이지 & 테마 패턴**:
   - **STAGE 1 - CLASSIC RAINBOW**: 6단 무지개 정통 벽돌 라인업
   - **STAGE 2 - PYRAMID OF RA**: 피라미드 형태와 중앙 강화 벽돌
   - **STAGE 3 - SPACE INVADER**: 침략자 외계인 형태의 편대와 폭탄 눈
   - **STAGE 4 - DIAMOND FORTRESS**: 외곽 은색 장갑으로 둘러싸인 난공불락 요새
   - **STAGE 5 - CHAOS MATRIX**: 티타늄 기둥과 연쇄 폭탄이 뒤엉킨 최종 전장 (이후 무한 루프 모드 지원)

2. **풍부한 파워업 아이템 시스템**:
   - ↔ **패들 확장 (Expand)**: 15초간 패들 가로폭이 넓어져 공을 받기 쉬워집니다.
   - ●● **멀티볼 3X (Multi-Ball)**: 현재 화면의 공을 3갈래로 분할 복제합니다.
   - ▲ **레이저 캐논 (Laser)**: 12초간 패들에서 트윈 레이저를 발사하여 벽돌을 직접 파괴합니다!
   - 🔥 **파이어볼 관통 (Fireball)**: 9초간 공이 벽돌에 튕기지 않고 모든 일반 벽돌을 뚫고 지나갑니다!
   - 🐢 **볼 슬로우 (Slow)**: 지나치게 빨라진 공들의 속도를 안정적인 기본 속도로 감속합니다.
   - 🛡️ **바닥 방어막 (Barrier)**: 하단에 에너지 라인을 전개하여 공의 낙하를 1회 막아줍니다.
   - ❤️ **생명 보너스 (Extra Life)**: 잔여 기회를 1회 회복합니다. (최대 5개)

3. **특수 벽돌 & 물리 반사 시스템**:
   - 💣 **폭탄 벽돌 (TNT)**: 타격 시 3x3 반경 주변 벽돌을 동시 폭파시키는 연쇄 폭발을 일으킵니다.
   - ⭐ **아이템 벽돌 (Mystery)**: 타격 시 100% 확률로 유용한 파워업 캡슐을 드롭합니다.
   - 🪨 **단단한 은색/금색 벽돌**: 2~3회 타격해야 파괴되며 균열(크랙)이 시각적으로 표시됩니다.
   - ⚙️ **패들 타격 각도 물리**: 패들의 중앙에 맞으면 수직으로, 외곽 모서리에 맞으면 날카로운 각도로 튕겨 전략적인 조준이 가능합니다.

4. **Web Audio API 8비트 사운드 신디사이저**:
   - 외부 음원 파일 다운로드 없이 브라우저 자체 오디오 합성으로 칩튠 효과음 구현.
   - 벽돌 연속 타격(콤보) 시 펜타토닉 음계가 점진적으로 상승하는 기분 좋은 청각 피드백.

5. **레트로 CRT 브라운관 스캔라인 필터**:
   - 버튼 하나로 1980~90년대 오락실 브라운관 모니터 스캔라인 효과를 켜고 끌 수 있습니다.

## 🕹️ 조작 방법

| 동작 | 키보드 | 마우스 / 터치 |
|---|---|---|
| **패들 이동** | `←` `→` 또는 `A` `D` | 마우스 가로 이동 또는 화면 터치 드래그 |
| **공 발사 / 레이저 사격** | `Space` 또는 `↑` | 마우스 좌클릭 또는 하단 발사 버튼 터치 |
| **일시정지 / 재개** | `P` 또는 `Esc` | 우측 상단 `[⏸ 일시정지]` 버튼 |
| **오디오 음소거 토글** | `M` | 우측 상단 `[🔊 사운드]` 버튼 |
| **CRT 스캔라인 토글** | `C` | 우측 상단 `[📺 CRT]` 버튼 |

## 🚀 실행 방법

### 방법 1. 단독 실행
- `breakout/index.html` 파일을 더블 클릭하여 웹 브라우저에서 바로 실행합니다.

### 방법 2. 아케이드 허브(Arcade Hub)에서 실행
- 프로젝트 루트 디렉터리의 `index.html` 또는 `start_hub.bat`를 실행하여 포털 메인에서 **브레이크아웃: 클래식 벽돌깨기** 카드를 클릭하여 플레이할 수 있습니다.
