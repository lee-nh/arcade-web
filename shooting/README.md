# AERO STRIKE 1995 (1990년대 스타일 비행기 아케이드 슈팅 게임)

1990년대 오락실의 황금기를 풍미했던 종스크롤 비행기 슈팅 게임(라이덴, 1945 스트라이커즈 등)의 감성을 그대로 재현한 HTML5 Canvas 기반 레트로 아케이드 게임입니다. 별도의 설치나 빌드 과정 없이 웹 브라우저에서 바로 실행할 수 있습니다.

---

## 🎮 주요 특징

1. **정통 1990년대 픽셀 아트 & 레트로 연출**
   - 캔버스 기반 픽셀 스프라이트 (플레이어 전투기, 정찰기, 인터셉터 요격기, 중형 폭격기, 거대 공중 요새 보스)
   - CRT 브라운관 스캔라인 필터 On/Off 지원
   - 타격감 넘치는 화면 흔들림(Screen Shake), 파편 폭발 이펙트 및 연기 파티클

2. **풍부한 시스템 & 무기 업그레이드**
   - **Lv.1**: 기본 2연장 속사 기관포
   - **Lv.2**: 3방향 확산 캐논
   - **Lv.3**: 4방향 확산 캐논 + 유도 미사일(Homing Missile) 발사
   - **Lv.4 (MAX)**: 5방향 파워 캐논 + 듀얼 유도 미사일
   - **[P] 파워업 아이템**: 무기 업그레이드 (MAX 시 보너스 점수)
   - **[B] 폭탄(Bomb) 아이템**: 화면 내 모든 적 탄환 제거 + 전 화면 대폭발 광역 피해 + 무적 시간
   - **[★] 황금 메달**: 추가 보너스 점수 획득

3. **단계별 적 구성 및 보스전**
   - 편대 비행 정찰기, 급강하 요격기, 원형 탄막을 쏘는 중형 폭격기
   - 3단계 공격 패턴과 전용 사이렌 경고 연출을 가진 보스 **"VULCAN TITAN"** (비행 요새)

4. **Web Audio API 기반 칩튠 사운드 & 다이내믹 BGM**
   - 외부 오디오 파일 없이 Web Audio API 신디사이저로 생성된 1990년대 FM 음원 스타일의 레이저, 타격, 폭발음
   - 베이스라인과 멜로디가 살아있는 레트로 아케이드 칩튠 BGM 루프 내장

5. **완벽한 크로스 플랫폼 지원**
   - 키보드 조작 (PC) 및 모바일/태블릿 가상 터치 D-패드 & 발사/폭탄 버튼 완벽 대응

## 🕹️ 조작법

| 기능 | 키보드 키 | 가상 패드 |
| :--- | :--- | :--- |
| **이동** | 방향키 (`↑`, `↓`, `←`, `→`) 또는 `W`, `A`, `S`, `D` | 가상 D-Pad |
| **사격** | `Space` 또는 `Z` (누르고 있으면 자동 연사) | `FIRE` 버튼 |
| **메가 폭탄** | `X` (전체 탄환 소거 & 화면 전체 피해) | `BOMB` 버튼 |
| **일시정지** | `P` | - |
| **소리 켜기/끄기** | `M` (또는 상단 `AUDIO` 버튼) | `AUDIO` 버튼 |
| **CRT 스캔라인** | 상단 `CRT: ON/OFF` 버튼 | `CRT` 버튼 |

## 🚀 실행 방법

### 방법 1: 브라우저에서 바로 열기
`index.html` 파일을 더블 클릭하여 크롬, 엣지, 파이어폭스, 사파리 등 현대 웹 브라우저에서 바로 실행합니다.

### 방법 2: 로컬 웹 서버로 열기 (선택 사항)
PowerShell 또는 터미널에서:
```bash
# Python 내장 서버 실행 시
python -m http.server 8000
```
이후 브라우저에서 `http://localhost:8000` 접속
