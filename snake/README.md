# 🐍 클래식 스네이크 게임 (Classic Snake Game)

웹 브라우저에서 바로 즐길 수 있는 클래식 지렁이(스네이크) 게임입니다.
지렁이가 붉은색 먹이를 먹을 때마다 몸통(꼬리)이 길어지고 점수가 올라갑니다!

---

## 🎮 실행 방법

별도의 설치나 라이브러리가 필요하지 않습니다.

1. **파일 탐색기**에서 `index.html` 파일을 더블 클릭하여 웹 브라우저(Chrome, Edge, Whale 등)로 바로 실행할 수 있습니다.
2. 또는 로컬 웹 서버(VS Code Live Server, Python `python -m http.server 8000` 등)를 통해 열 수도 있습니다.

---

## 🕹️ 조작 방법

- **이동:**
  - 키보드 방향키: `▲` `▼` `◀` `▶`
  - WASD 키: `W`(위), `A`(왼쪽), `S`(아래), `D`(오른쪽)
  - 화면 하단 가상 방향키 패드 (마우스 클릭 또는 스마트폰/태블릿 터치)
  - 스마트폰 화면 스와이프 (상/하/좌/우 드래그)
- **일시정지:** `Space` 바 또는 ⏸️ 버튼
- **사운드 켜기/끄기:** 우측 🔊 버튼

---

## ✨ 주요 기능

1. **클래식 규칙 완벽 구현**
   - 먹이를 먹으면 꼬리가 1칸씩 늘어나고 점수 +10점 획득
   - 벽이나 자기 몸에 충돌하면 게임 오버
2. **반응형 & 네온 아케이드 비주얼**
   - 뱀 머리의 눈동자가 이동 방향을 주시
   - 몸통으로 갈수록 부드러운 그라데이션 적용
3. **효과음 내장 (Web Audio API)**
   - 별도 외부 mp3/wav 파일 다운로드 없이 브라우저 자체 오디오 신디사이저로 레트로 아케이드 효과음 제공
4. **최고 점수 저장**
   - 브라우저의 `localStorage`를 활용하여 새로고침하거나 창을 닫아도 최고 기록(BEST) 유지
5. **난이도 설정**
   - 쉬움 / 보통 / 어려움 선택 가능
