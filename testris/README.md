# 🎮 모던 클래식 테트리스 (Modern Classic Tetris)

웹 브라우저에서 바로 즐길 수 있는 깔끔하고 세련된 네온 다크 테마의 테트리스 게임입니다.

별도의 설치나 웹 서버 설정 없이 `index.html` 파일을 더블 클릭하기만 하면 모든 브라우저(크롬, 엣지, 웨일, 사파리 등)에서 즉시 플레이할 수 있습니다.

---

## ✨ 주요 기능

1. **정통 7-Bag 테트로미노 시스템**
   - I, J, L, O, S, T, Z 7가지 블록이 공정하고 균등하게 등장합니다.
2. **벽 킥 (Wall Kick) & 회전 보정**
   - 벽이나 기존 블록과 인접해 있을 때도 회전이 자연스럽게 적용됩니다.
3. **고스트 피스 (Ghost Piece)**
   - 블록이 수직 낙하했을 때 착지할 위치를 반투명한 외곽선으로 미리 확인할 수 있습니다.
4. **홀드 (Hold) 기능**
   - 곤란한 블록을 킵해두고 나중에 꺼내 쓸 수 있습니다. (한 턴당 1회)
5. **다음 블록 (Next Piece) 미리보기**
   - 다음에 내려올 블록을 사전에 파악하여 전략적인 배치가 가능합니다.
6. **Web Audio API 신디사이저 사운드**
   - 외부 오디오 파일 다운로드 없이 브라우저 자체 음원 합성으로 이동, 회전, 착지, 줄 삭제, 게임 오버 사운드를 재생합니다. (우측 상단 🔊 버튼으로 음소거 가능)
7. **레벨 & 스코어 & 최고 점수 보존**
   - 10줄을 제거할 때마다 레벨이 오르며 블록 낙하 속도가 빨라집니다.
   - 브라우저 LocalStorage에 최고 점수(High Score)가 자동 저장됩니다.
8. **반응형 & 모바일 터치 지원**
   - 스마트폰이나 태블릿 등 모바일 화면에서도 온스크린 터치 버튼으로 편리하게 조작할 수 있습니다.

---

## 🕹️ 조작 방법 (Controls)

| 키 | 동작 | 설명 |
|---|---|---|
| <kbd>←</kbd> <kbd>→</kbd> | 좌 / 우 이동 | 블록을 한 칸씩 좌우로 이동 |
| <kbd>↑</kbd> | 시계방향 회전 | 블록을 오른쪽(시계방향)으로 90도 회전 |
| <kbd>Z</kbd> | 반시계방향 회전 | 블록을 왼쪽(반시계방향)으로 90도 회전 |
| <kbd>↓</kbd> | 소프트 드롭 (Soft Drop) | 블록을 빠르게 아래로 이동 (추가 점수) |
| <kbd>Space</kbd> | 하드 드롭 (Hard Drop) | 블록을 바닥으로 즉시 낙하 및 고정 |
| <kbd>C</kbd> 또는 <kbd>Shift</kbd> | 홀드 (Hold) | 현재 블록을 보관함과 교체 |
| <kbd>P</kbd> 또는 <kbd>Esc</kbd> | 일시 정지 (Pause) | 게임 일시 정지 및 재개 |

## 🚀 실행 방법

1. 탐색기에서 `game_test_2` 폴더로 이동합니다.
